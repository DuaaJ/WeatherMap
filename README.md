WeatherMap

Live Demo:  https://duaaj.github.io/WeatherMap/

APIs Used
1.OpenWeatherMap
2.Nominatim API

Setup Instructions
1.Clone this repository
2.Obtain a free API key from OpenWeatherMap
3.Open the project folder in Visual Studio Code.
4.Open map.js and replace the existing key with your own
5.Open with Live Server
6.Type a city name and click Get Weather
